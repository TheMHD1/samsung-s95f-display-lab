# Panel research provenance

Start with the [Mobile Demura and panel-flashing dossier](../../docs/advanced/panel/README.md). [sources.json](sources.json) records SHA256 hashes and local relative identifiers for the retained evidence behind the mobile, storage and blackout chapters. It contains no raw reports, OEM firmware or owner calibration.

The [offline format inspector](../README.md) models selected USB/header/layout/checksum facts. It does not contact a TV, acquire a backup or write a panel. A successful format check does not establish storage freshness or optical coefficient meaning.
